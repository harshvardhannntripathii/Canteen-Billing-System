## Function Call Flow

```
main()
  ├── initializeMenu()
  ├── displayMenu()
  ├── searchFoodItem()
  │     └── findItemIndex()
  ├── placeOrder()
  │     ├── findItemIndex()
  │     ├── getValidQuantity()
  │     └── clearInputBuffer()
  ├── generateBill()
  │     ├── findItemIndex()
  │     └── clearInputBuffer()
  ├── viewAvailableStock()
  ├── getValidChoice()
  ├── getValidPrice()
  ├── getValidQuantity()
  └── clearInputBuffer()
```

## Data Flow

```
MENU ARRAY (FoodItem[20])
    │
    ├── initializeMenu() → Populates 12 items
    │
    ├── displayMenu() → Reads all items
    │
    ├── searchFoodItem() → Reads one item by ID
    │
    ├── placeOrder() → Reads items, writes to ORDER ARRAY
    │
    ├── generateBill() → Reads ORDER ARRAY
    │     ├── Confirmed: Updates MENU ARRAY (stock--)
    │     └── Cancelled: No changes
    │
    └── viewAvailableStock() → Reads all items
```

## Control Flow Summary

1. **Sequential**: Program starts → Initializes → Shows Menu
2. **Iterative**: Main menu loop (do-while until exit)
3. **Selection**: Switch-case for menu options
4. **Validation Loops**: Input validation with while(1) loops
5. **Nested Loops**: Order placement loop (add multiple items)
6. **Function Calls**: Modular design with 10+ functions
