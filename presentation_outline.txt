## Slide 4: Data Structures
**FoodItem Structure**
```c
typedef struct {
    char id[10];        // Food ID (e.g., "101")
    char name[50];      // Food Name (e.g., "Burger")
    float price;        // Unit Price (e.g., 50.00)
    int quantity;       // Available Stock (e.g., 20)
} FoodItem;
```

**OrderItem Structure**
```c
typedef struct {
    FoodItem item;      // Copy of food item
    int orderedQuantity; // Quantity ordered
    float subtotal;     // price × quantity
} OrderItem;
```

**Global Arrays**
- `FoodItem menu[MAX_ITEMS]` - 12 pre-loaded items
- `OrderItem orders[MAX_ORDERS]` - Current order cart

## Slide 6: Search Functionality
**Search Food Item (Option 2)**

**Process:**
1. User enters Food ID
2. `findItemIndex()` searches menu array
3. If found: Display name, price, quantity, status
4. If not found: Error message

**Demo Input:** `101`
**Demo Output:**
```

Food Name  : Burger
Price      : ₹50.00
Available  : 20
Status     : Available
```

**Error Case:** Invalid ID `999` → "Food item not found!"

## Slide 8: Bill Generation
**Generate Bill (Option 4)**

**Bill Format:**
```
BILL RECEIPT

Item           Qty  Unit Price  Subtotal
----------------------------------------
Burger          2     ₹50.00     ₹100.00
Samosa          3     ₹15.00      ₹45.00
----------------------------------------
Grand Total:              ₹145.00
```

**Confirmation Process:**
1. Display itemized bill
2. Ask "Confirm order? (y/n)"
3. If YES:
   - Deduct stock from menu array
   - Show updated stock
   - Clear order cart
4. If NO:
   - Keep items in cart
   - No stock changes

## Slide 10: Input Validation
**Comprehensive Error Handling**

| Input Type | Validation | Error Message |
|------------|------------|---------------|
| Menu Choice | 1-6 only | "Invalid choice! Enter 1-6" |
| Food ID | Must exist | "Invalid Food ID!" |
| Quantity | > 0, ≤ Stock | "Insufficient stock!" |
| Quantity | Numeric only | "Invalid input!" |
| Confirmation | y/n only | Re-prompts |

**Validation Functions:**
- `getValidChoice(min, max)` - Menu choices
- `getValidQuantity(maxStock)` - Order quantities
- `getValidPrice()` - Price inputs
- `clearInputBuffer()` - Clears stdin
