## How to Run Tests

1. Compile the program:
   ```bash
   gcc canteen_billing.c -o canteen_billing
   ```

2. Run the program:
   ```bash
   ./canteen_billing
   ```

3. Enter inputs as shown in each test case

4. Verify outputs match expected results

5. For automated testing, you can pipe inputs:
   ```bash
   echo -e "3\n101\n2\n104\n3\n0\n4\ny\n6" | ./canteen_billing
   ```
